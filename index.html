Vision in the latent space of a learned codec

prototype

Research prototype · PyTorch

Image classification run directly on the latents of a learned image codec (hyperprior, JPEG AI-like), skipping pixel decoding. A light latent network is 24× cheaper than decode-then-ResNet-18, and an input ablation shows the hyperprior and σ map carry most of the semantic signal.

bitstream→ŷ, μ, σ, ẑ→latent CNN→class
  • learned compression
  • efficient inference
  • ablation study

Object detection in satellite images

graduation project

Engineering graduation project · HIAST · 2023

Satellite images are huge and their objects are tiny, so standard detectors miss most of them. I compared state-of-the-art detectors, YOLOX and YOLO-NAS, and combined them with SAHI (Slicing Aided Hyper Inference): the image is cut into overlapping slices, each slice is detected at full resolution, and the results are merged back. The work balanced speed against accuracy for large-scale images, with applications in disaster response, urban planning and environmental monitoring.

satellite image→overlapping slices→YOLOX / YOLO-NAS→merged detections

Supervised by Prof. Omar Hamdoun

  • YOLOX
  • YOLO-NAS
  • SAHI
  • small-object detection
  • satellite imagery

Object detection for a visual question answering corpus

top mark

4th-year engineering project · HIAST · highest mark of the cohort

A visual question answering (VQA) corpus pairs images with questions and answers about them, so it first needs to know what each image contains. I built the deep-learning object detection stage: it finds the objects in every image with their class and location, which become the grounded facts used to build question–answer pairs such as “how many cups?” or “what is next to the book?”.

images→object detector→objects + boxes→Q/A pairs
